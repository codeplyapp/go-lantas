# 🛡️ SIGAP — Sistem Inovasi Generasi Aman berlalu lintas dan Peduli

Aplikasi Prototipe Web Pendukung Naskah LKTI Korlantas POLRI 2026.

## 🚀 Direktori Aplikasi Utama
Aplikasi prototipe web terletak di dalam folder [`demo-sigap/`](./demo-sigap/):

```bash
cd demo-sigap
npm install
npm run dev
```

Buka `http://localhost:5173` di browser Anda.

Panduan lengkap, skrip presentasi dewan juri, dan cara integrasi Gemini AI Key dapat dilihat pada file [demo-sigap/README.md](./demo-sigap/README.md).
